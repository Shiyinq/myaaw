# Contributing to Myaaw 🐾

Thank you for your interest in contributing to Myaaw! We welcome contributions from the community to help make Myaaw the best AI cat assistant.

## How to Contribute

1.  **Fork the Repository**: Create your own copy of the project.
2.  **Create a Branch**: `git checkout -b feature/your-feature-name`.
3.  **Make Changes**: Implement your feature or fix.
4.  **Run Tests**: Ensure everything works (we are working on more tests!).
5.  **Submit a Pull Request**: Explain your changes and why they are needed.

## Reporting Bugs

- Use the [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md).
- Provide as much detail as possible, including logs and environment info.

## Feature Requests

- Use the [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.md).
- Describe the problem you want to solve and how the feature helps.

## Code of Conduct

Be kind, respectful, and helpful to others. We are all here to build something cool!
